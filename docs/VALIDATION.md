## 范围与限制

- 已完成 SQLite 及 MySQL 5.7.44 备份升级演练；MariaDB、其他历史版本和第三方修改仍需按实际环境验证。
- 月初流量重置是原版正常业务；静态数据比对仅在本地 Redis 暂时持有调度锁，以区分业务写入和升级影响，没有修改调度/重置代码。
- MySQL 测试使用独立的静态升级库和功能写入库；原始 SQL、环境文件和接口原文不进入源码或公开报告。没有进行公网、真实支付、邮件发送或长期压力测试；已有 WS 实现保持不变。
- SQL 备份不含生产 `.env`、真实 APP_KEY、主题包和用户插件文件；本地用测试配置及已有本地资源模拟挂载。生产必须保留原有实际文件，原密码哈希等数据已在全表比对中验证保留。
- 无外网出口的测试网络没有默认路由，因此 sing-box 有 `missing default interface` 提示；本地证书校验、WS 及 HY2 请求实际通过，未为消除提示而更改宿主机网络。
- 沿用上游锁定依赖。上游 `composer.lock` 的内容哈希与 `composer.json` 存在原有不同步警告；本轮不改变其依赖版本，安装及全部测试通过。
- 本地镜像完成启动/联动验收，不表示已发布 GitHub 仓库、Release 或公共面板镜像。

升级和回退步骤见 [UPGRADE-XBOARD-U.md](UPGRADE-XBOARD-U.md)。不要用新装、重建数据库或重生成 APP_KEY 的命令升级已有面板。
