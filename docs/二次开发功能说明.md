# 二次开发功能说明

xboard-u 基于原版 Xboard，配合 [xboard-node-u](https://github.com/Toto0912/xboard-node-u) 使用。本页介绍二次开发增加或调整的功能，安装和更新方式见 [README](../README.md)，发布状态见 [变更记录](../CHANGELOG.md)。

## 节点 Fallback

支持 VLESS / Trojan，传输为 TCP/RAW，安全性为 TLS 或 Reality。符合这些条件时，编辑节点的安全性设置下方、传输协议设置上方会显示可选的 `Fallback` 输入框；切换为其他传输或关闭安全性时隐藏。

填写 `域名:端口`、`IP:端口` 或 `[IPv6]:端口`，例如 `site.example.com:443`、`127.0.0.1:8080`、`[::1]:8443`。有效输入会保存并下发；空值、格式不正确或不适用当前协议组合的输入，在保存时按空值处理，不阻止保存节点。

面板和节点端均须使用包含此功能的版本。Xray 内核的机器模式、单节点模式都支持；sing-box 节点忽略此项。该配置只供服务端使用，不写入客户端订阅，也不改变客户端连接地址、SNI 或 Reality 公钥。

### TLS 普通回落

填写 TLS 解密后的后端地址，例如本机明文 HTTP 网站 `127.0.0.1:8080`。Xray 配置协议层回落，默认协商 HTTP/1.1；浏览器访问节点的 HTTPS 端口时，非代理请求进入网站，合法代理请求照常使用。

普通 TLS 回落不能与 VLESS 额外加密同时启用。存在不兼容的加密配置时，输入框禁用并提示原因，保存时清空回落配置。

### Reality“偷自己”

填写 HTTPS 目标地址，例如本机 Nginx 的 `127.0.0.1:8443`。节点端将其作为 Reality 伪装目标，保留原有 SNI、公私钥和 Short ID。目标须支持 TLS 1.3，证书匹配安全性设置中的 SNI。

例如 Xray 监听 `443`，Nginx HTTPS 网站监听 `127.0.0.1:8443`，在面板 Fallback 中填写 `127.0.0.1:8443`，即可让普通浏览器访问进入该网站，同时保持合法 Reality 代理连接。

Reality 使用自己的目标站转发机制，与普通 TLS 解密后的回落不同。两种模式的回落地址都不能指回节点自身监听端口；留空时沿用原版行为。回落设置复用现有节点 JSON 配置，不新增数据库列，也不需要重新安装面板。

## TLS 内容推送保存修复

修复 HY2 等节点的 TLS 内容推送配置保存后，重新打开高级设置却显示为空的问题。兼容原有空证书配置，保存并保留证书、私钥及相应设置。

## 机器安装命令

添加或编辑机器时，可复制的安装命令使用 xboard-node-u 的正式 Release 资源。支持普通 Linux 的 systemd 安装及 Alpine Linux / OpenRC 安装，默认使用 sing-box 内核。

## 默认订阅模板

更新以下三份默认模板：

| 客户端 | 默认模板文件 |
| --- | --- |
| sing-box 1.14 | [default.sing-box.json](../resources/rules/default.sing-box.json) |
| Clash | [default.clash.yaml](../resources/rules/default.clash.yaml) |
| Clash Meta / Stash | [共用 default.clashmeta.yaml](../resources/rules/default.clashmeta.yaml) |

新装面板使用这些默认内容。升级时仅自动替换已知的原版默认模板，保留管理员已自定义的模板及其他类型模板，并避免旧 Redis 缓存继续返回旧默认内容。已有自定义模板需要换用新模板时，可在面板订阅模板设置中自行替换。

## 部署与原版迁移

保留原版数据库、主题及节点通信接口，支持从原版迁移。提供 Linux amd64 / arm64 Docker 镜像 `ghcr.io/toto0912/xboard-u:latest`，Docker 构建使用当前项目源码和固定版本的管理前端资源。

- [aaPanel + Docker 部署](AAPANEL-MYSQL-UPGRADE.md)
- [从原版 Xboard 迁移](UPGRADE-XBOARD-U.md)

Fallback 管理界面扩展在 Docker 构建时自动生成，不修改上游前端子模块。手动从源码构建时，执行 `php scripts/prepare-admin-assets.php` 生成；如果固定的上游资源发生变化，构建会提示需要重新检查扩展。
