# Xboard-u v2.4.1

本版配套 xboard-node-u v2.4.1，更新节点权限同步、流量入账和订单结算。面板升级会执行数据库迁移。

## 主要变化

- **流量**。节点上报批次落库后才收到回执，重传同一批次只计费一次。面板在迁移完成后自动协商新协议，旧节点仍可使用原上报方式。修复 PostgreSQL 账务写入对大流量和小数倍率的处理。
- **节点权限**。封禁、自然到期、移组和删除用户后按节点更新名单，兼容权限组的数字与字符串 ID。节点失联后恢复连接时会重新核对名单。
- **支付与对账**。结账时保存渠道、报价和手续费；BTCPay 与 CoinPayments 增强币种、金额及回调校验。同一笔到账只开通一次，多付和已取消订单的到账可分别查询。旧 Coinbase Commerce 渠道自动停用。
- **套餐与订单**。待付及处理中的订单会占用限量套餐名额，礼品卡和注册试用遵守同一容量限制。限量优惠券取消后释放；一次性流量包换购只记录实际参与折抵的旧单。支付开通和流量重置在同一事务内完成。
- **注册与返佣**。一次性邀请码随注册事务核销，注册失败可重新使用。管理员编辑邀请人和返佣结算均检查邀请环。

## 升级

1. 备份数据库、`.env` 和持久化目录，保留当前面板与节点版本。升级时先更新面板的所有实例，确认数据库迁移完成，再更新节点。
2. 配套 Compose 会在启动时执行 `php artisan xboard:update`。自建队列须让新版 worker 消费 `traffic_batch`，并保持 Laravel 每分钟调度。运行 `php artisan traffic:batches --status` 查看待处理批次。
3. 保留节点的流量持久化目录和节点 ID。旧协议下已发送但丢失回执的上报无法追溯去重，升级前的优惠券订单也不会回填占用记录。
