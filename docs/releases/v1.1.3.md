# xboard-u v1.1.3

支持原生自定义出站与路由，配合 xboard-node-u v1.1.3 使用。

- Sing-box 原生 type 出站无需套 protocol/settings；原生 detour、TLS、transport 等字段完整保留。
- Xray 原生出站保留 streamSettings、proxySettings、mux 等字段。
- 兼容旧面板格式；旧 proxy_tag 在 Sing-box 下转换为 detour。
- 检查错误内核格式、未知出站引用和依赖循环；未知原生参数交由实际内核解析，避免面板白名单限制新字段。
- 保留 JSON 空对象；自定义配置仅下发服务器，不进入客户端订阅。
- 自定义路由编辑区只读显示当前节点入站标签，随协议更新，不提供复制按钮。
- 更新脱敏示例：Xray 使用扁平 SOCKS 配置，Sing-box 使用原生 SOCKS 出站及 inbound 标签路由。
- 不新增数据库迁移，保留已有配置和订阅模板。

升级时保留已有数据库与配置。先更新节点端，再使用新的原生配置；已有旧格式不需要改写。

## 更新

先更新节点端到 v1.1.3，再使用新的 Sing-box 原生出站。在现有面板部署目录执行：

```sh
docker compose pull && docker compose up -d
```

使用固定版本镜像的部署，将镜像改为 `ghcr.io/toto0912/xboard-u:v1.1.3`；使用 latest 的部署沿用原命令。保留原数据库、APP_KEY、主题和挂载目录，无需重新初始化。

配置说明：[自定义出站](https://github.com/Toto0912/Xboard-u/blob/v1.1.3/docs/CUSTOM-OUTBOUNDS.md)、[自定义路由](https://github.com/Toto0912/Xboard-u/blob/v1.1.3/docs/CUSTOM-ROUTES.md)。

本地隔离验证：面板 SQLite 全量 60 项测试、477 个断言通过；MySQL 5.7 配置/证书/Fallback 回归 15 项测试、326 个断言通过。双内核、单节点/机器模式、原生/旧格式共8个真实节点，初始与自动更新后16次流量检查通过。入站标签展示另外通过组件检查和管理资源生成检查。
