# xboard-u v1.1.0

配合 **xboard-node-u v1.1.0 或更新版本**，支持从面板配置 Xray 回落，并更新默认订阅模板。

- VLESS / Trojan 在 TCP/RAW + TLS / Reality 下增加可选 Fallback，位于安全性与传输协议设置之间。无效输入保存为空，切换到不支持的协议组合时不启用。
- Xray + TLS 使用普通回落，例如明文 HTTP 后端 `127.0.0.1:8080`，默认 HTTP/1.1；与 VLESS 额外加密不兼容。
- Xray + Reality 使用 HTTPS 伪装目标，例如 `127.0.0.1:8443`，实现“Reality 偷自己”。目标需支持 TLS 1.3，证书匹配原 SNI；保留原密钥、Short ID 和客户端参数。
- 支持机器及单节点模式的 REST / WebSocket 下发；sing-box 节点忽略回落配置，客户端订阅不包含服务端回落字段。
- 更新 sing-box 1.14、Clash、Clash Meta / Stash 默认订阅模板。数据迁移仅替换已知旧默认内容，保留管理员自定义模板，不新增数据库列。
- README 简化为文档入口，详细使用方法见[二次开发功能说明](https://github.com/Toto0912/Xboard-u/blob/v1.1.0/docs/二次开发功能说明.md)。

开发阶段已通过面板 35 项测试、本次功能 MySQL 5.7 专项 9 项测试、管理表单交互检查及 16 个节点的本地联调。完整 sing-box 1.14.4 实际订阅通过原生解析。发布过程另由仓库的自动发布校验把关。

## 更新

先备份数据库和配置，再在原 Docker 安装目录执行：

```bash
docker compose pull && docker compose up -d
```

保留原数据库、APP_KEY、主题和挂载目录，不要重新初始化。使用 Fallback 时，还需将对应节点端升级到 v1.1.0 或更新版本；建议先更新节点端，再更新面板。

镜像：`ghcr.io/toto0912/xboard-u:v1.1.0`；验证通过后同样更新 `latest`，提供 Linux amd64 / arm64 两种架构。发布附件包含安装脚本、固定版本 Compose 文件、带管理前端的源码包、许可证和 SHA256 校验清单。
