# xboard-u v1.1.2

与 xboard-node-u v1.1.2 统一采用 Xray 原生协议层回落。

- TLS / Reality 的面板 Fallback 均下发为协议层回落；Reality 原目标、SNI、密钥、Short ID 和客户端参数保持原样。
- 普通浏览器 / Reality 鉴权失败仍进入原 HTTPS 目标，通过 Reality 握手后的代理协议失败才进入回落后端。
- 保持可选单目标输入、无效值清空、sing-box 忽略及客户端订阅字段隔离；VLESS 额外加密在 TLS / Reality 下都不兼容回落。
- 不新增数据库迁移，不改变已有模板。升级前检查曾用于覆盖 Reality 目标的旧 Fallback，区分 HTTPS 目标与明文回落后端，并一并升级节点端到 v1.1.2。

本地隔离验证通过：面板 SQLite 全量 56 项测试、351 个断言；MySQL 5.7 回落专项 6 项测试、161 个断言；与节点端的 16 个面板节点、独立示例及 WebSocket 配置更新联调通过。客户端订阅不泄漏回落目标，完整 sing-box 1.14 订阅通过原生解析。

详细用法与升级注意事项见[二次开发功能说明](https://github.com/Toto0912/Xboard-u/blob/v1.1.2/docs/二次开发功能说明.md#节点-fallback)。

## 更新

**请同时更新面板和节点端到 v1.1.2，并在更新前检查旧 Reality Fallback：它现在表示协议层回落后端，不再是 HTTPS 伪装目标。** 已有数据不会自动清空或改写。

在现有面板部署目录执行：

```sh
docker compose pull && docker compose up -d
```

使用固定版本镜像的部署先改为 `ghcr.io/toto0912/xboard-u:v1.1.2`；使用 `latest` 的部署直接执行上述更新命令。保留原数据库、APP_KEY、主题与挂载目录，不要重新初始化。

对应节点端使用 `xbctl upgrade` 更新。
