# xboard-u v2.3.0

新增 HY2 端口跳跃，配套 xboard-node-u v2.3.0。

## 新增功能

- 连接端口和服务端口支持单端口或连续范围，例如 60000-65000。
- 连接端口下方新增跳跃间隔：10 为固定 10 秒，10-30 为每次重新随机的 10～30 秒；留空默认 30 秒，最小 5 秒。
- 配套节点端只监听首端口，自动将范围内其余 UDP 端口转发到首端口，保留一个入站及统一用户／流量统计。
- 适配客户端／服务端分离、同步配置、完整范围回显、中英俄三语、日夜主题及移动端布局。
- 按客户端能力转换随机或固定间隔；旧版／未知客户端使用兼容降级。服务端专用配置不进入订阅。

## 修复与兼容

- 修复 HY2 可空带宽、TLS、混淆字段导致的配置构建异常。
- 修正 Shadowrocket 将跳跃间隔误写成 keepalive 的映射。
- 不新增数据库结构迁移。server_port 保留整数首端口，完整范围与随机上限使用现有 JSON 配置列。
- 原有带宽方向、BBR / Brutal、证书、Masquerade、用户和流量统计继续沿用。

## 升级

先升级节点端至 v2.3.0，再配置服务端范围。确认 Linux 上存在可用的 nftables 或 iptables/ip6tables、具备网络管理权限，并在云安全组与主机防火墙放行对应 UDP 范围。服务端填写单端口时仍可由管理员管理外部映射；普通 HTTP CDN 不会因此支持 HY2 UDP。

面板在现有安装目录更新：

~~~sh
docker compose pull && docker compose up -d
~~~

升级前保留数据库与配置备份。安装／迁移命令与原有方式一致。

## 验证

本地隔离 SQLite 与 MySQL 5.7 各通过 168 tests / 1922 assertions；验证保存重开、REST / WebSocket、订阅降级、三语及日夜／移动布局。配套节点两种内核、IPv4/IPv6、三种模式接入和自动清理已验证。公网、实际 LXC 及 iOS 客户端未实机测试。
