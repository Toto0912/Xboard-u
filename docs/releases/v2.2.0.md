# xboard-u v2.2.0

新增 HY2 Masquerade 编辑与自动带宽协商，完善 Stash XHTTP 和旧版 Clash 订阅，配套 xboard-node-u v2.2.0。

## 同版本修复：Stash 与 Clash 订阅

- 补齐 Stash VLESS + XHTTP 的 network / xhttp-opts、上下行分离、独立 TLS / Reality / SNI / ALPN、请求头及官方支持的填充参数。iOS/tvOS 需 3.6+，macOS 需 4.3+；识别到旧版本时跳过不支持的节点。
- Stash 保留已启用的 VLESS Encryption。XHTTP 上使用 Vision 时必须同时配置 Encryption；不能等价转换的配置会跳过，不会降级成 TCP。
- 修复旧版 Clash 默认模板使用 RULE-SET / GEOSITE / AND 等扩展规则导致的导入失败，使用基础 DNS / 分流模板；补齐 VMess HTTP/2，过滤不支持的传输与 Reality。
- Clash / Stash 没有兼容节点或正则匹配为空时，保留分组和引用，并使用内置 DIRECT 策略；不伪造代理节点。
- 数据迁移只替换项目自带的旧 Clash 默认模板，保留管理员自定义内容，不修改 Mihomo / Stash 默认模板。更新缓存代次避免继续使用旧默认。原版 Clash 不支持 VLESS、Reality、HY2 或 XHTTP；套餐只有这些节点时仍需换用兼容客户端和订阅格式。

## HY2 增强

- HY2 面板带宽保持客户端视角，下发服务端时仅交换一次上下行；客户端订阅保持原方向。支持 CDN 分离后的服务端配置。
- 增加 Masquerade JSON 编辑器，按实际服务端内核提供 file / proxy / string 完整类型示例、官方链接、预览确认、格式化及恢复默认。
- 带宽留空时要求 BBR，填写正值时允许按双方较小限制协商 Brutal；客户端未提供带宽时仍可采用 BBR。QUIC 窗口、超时、MTU 等保持内核默认，不新增调参入口。
- 服务端专用字段不进入客户端订阅；支持保存重开、各内核草稿、无效 JSON 拦截、中英俄语言及日夜主题。
- Masquerade 工具栏的选择框、按钮与链接统一高度、字号和垂直对齐，窄布局可换行。

## 升级

继续使用 v2.2.0，不需要新版本号。已安装先前 v2.2.0 的用户也需重新拉取镜像并重建服务：

```bash
docker compose pull && docker compose up -d
```

此次订阅修复仅更新面板，节点端无改动。面板会执行默认 Clash 模板的数据迁移，不新增数据库列；管理员自定义模板不会被覆盖，其中的旧 Clash 不兼容语法需自行调整。

如果此前尚未升级 HY2 增强，先将节点端更新至 v2.2.0，再按原流程更新面板。仅更新面板不能让旧节点端识别 Masquerade。**请核对原 HY2 带宽：此前 Sing-box 未应用的正值现在会生效，面板上下行也将按正确方向下发。** HY2 带宽协商与用户套餐限速不同，Hysteria 1 保持原有行为。

配置详情：[二次开发功能说明](https://github.com/Toto0912/Xboard-u/blob/v2.2.0/docs/二次开发功能说明.md)、[HY2 配置说明](https://github.com/Toto0912/Xboard-u/blob/v2.2.0/docs/HYSTERIA2.md)、[Stash 官方 XHTTP 文档](https://stash.wiki/en/proxy-protocols/proxy-types#xhttp)。

## 验证

此次订阅修复的本地隔离测试：SQLite、MySQL 5.7 完整回归各 **138 项 / 1630 个断言**通过。原版 Clash v1.18.0 接受 9 份完整订阅，并在实际启动后的 API 中识别 SS、VMess、Trojan、SOCKS5、HTTP 五类节点。

Stash 已验证控制器、版本过滤、完整 YAML、上下行字段和私密信息隔离；本地 Windows 环境未运行 iOS/macOS Stash 真机，实际设备导入与连接仍需验证。Clash 未连接生产节点。公网吞吐与长期压测不在此次范围。

此前 HY2 更新已通过浏览器编辑器验证、节点全量 race、24 组真实 HY2 场景及独立模式程序验证。
