# xboard-u v2.2.0

新增 HY2 Masquerade 编辑与自动带宽协商，配套 xboard-node-u v2.2.0。

- HY2 面板带宽保持客户端视角，下发服务端时仅交换一次上下行；客户端订阅保持原方向。支持 CDN 分离后的服务端配置。
- 增加 Masquerade JSON 编辑器，按实际服务端内核提供 file / proxy / string 完整类型示例、官方链接、预览确认、格式化及恢复默认。
- 带宽留空时要求 BBR，填写正值时允许按双方较小限制协商 Brutal；客户端未提供带宽时仍可采用 BBR。QUIC 窗口、超时、MTU 等保持内核默认，不新增调参入口。
- 服务端专用字段不进入客户端订阅；支持保存重开、各内核草稿、无效 JSON 拦截、中英俄语言及日夜主题。
- Masquerade 工具栏的选择框、按钮与链接统一高度、字号和垂直对齐，窄布局可换行。

## 升级

先将节点端更新至 v2.2.0，再按原流程更新面板；没有新增数据库迁移或必填配置。仅更新面板不能让旧节点端识别 Masquerade。

```bash
docker compose pull && docker compose up -d
```

**请核对原 HY2 带宽：此前 Sing-box 未应用的正值现在会生效，面板上下行也将按正确方向下发。** HY2 带宽协商与用户套餐限速不同。Hysteria 1 保持原有行为。

配置详情：[HY2 配置说明](https://github.com/Toto0912/Xboard-u/blob/v2.2.0/docs/HYSTERIA2.md)。

## 验证

本地隔离测试：SQLite、MySQL 5.7 完整回归各 117 项 / 1482 个断言；浏览器验证两内核六类示例、保存重开、非法 JSON、取消、CDN 内层配置、中英俄文与工具栏对齐。配套节点端通过全量 race、24 组真实 HY2 场景及独立模式程序验证。公网吞吐与长期压测不在此次验证范围。
