# xboard-u v2.1.1

为 Mihomo / Clash Meta、Stash 订阅输出的 Reality 配置自动添加 `reality-opts.support-x25519mlkem768: true`，让支持该选项的客户端提供 X25519MLKEM768 密钥交换能力。

- Mihomo 覆盖 VLESS、Trojan Reality 节点，以及 XHTTP 上下行分离中的 Reality 下行。
- Stash 为现有转换所输出的 Reality 节点添加相同字段，保留既有协议与版本筛选；当前仍过滤 Trojan Reality，不因本次更新开放新协议或传输。
- 字段以 YAML 布尔值 `true` 输出，保持公钥、Short ID、SNI 及源配置不变；普通 TLS、明文连接、Sing-box 和通用订阅、服务端配置不添加该字段。
- 无需额外开关或修改订阅模板；README、更新记录和二次开发功能说明同步更新。

本地验证在独立副本中完成：42 项测试、400 个断言全部通过，覆盖两种订阅的 Reality 字段、普通 TLS 隔离、XHTTP 下行、原有协议筛选和服务端配置隔离。此前生成的 Mihomo 配置也通过原生校验；未进行 Stash Apple 客户端的实机连接测试。该选项不替代客户端版本、指纹及服务端的其他握手要求。

本次仅更新面板，兼容 xboard-node-u v2.1.0，无需为此单独升级节点端。不新增数据库迁移，不调整 Loon 订阅。按原更新方式拉取镜像并重建面板后，客户端刷新订阅即可获取新字段。
