# xboard-u v1.1.1

补齐 VLESS + XHTTP 的 Clash Meta / Mihomo 上下行分离订阅转换，可继续搭配 xboard-node-u v1.1.0 使用。

- 自动将 Xray `extra.downloadSettings` 转成 Mihomo 原生 `download-settings`，转换下行地址、端口、TLS / Reality、SNI、ALPN、指纹及传输参数。
- 转换常用 XHTTP 高级参数和 XMUX，处理上下行默认值及继承差异。
- 对无法等价转换或格式不正确的节点，跳过该节点并记录原因，保留其他有效节点，不静默丢弃分离设置。
- 保留节点 API、原始配置、默认/自定义模板和其他客户端订阅规则；不新增数据库迁移。可继续搭配 xboard-node-u v1.1.0。

配置方法和兼容范围见[二次开发功能说明](https://github.com/Toto0912/Xboard-u/blob/v1.1.1/docs/二次开发功能说明.md#xhttp-上下行分离订阅v111)。

## 本地验证

- PHP 8.2.35 / PHPUnit 11.5.27：56 项回归测试、347 项断言通过。
- Mihomo v1.19.33：明文 / TLS / Reality 的九种上下行安全组合通过原生配置校验；该项不等同于九种组合均完成实际连接测试。
- xboard-node-u v1.1.0 Xray 机器模式、本地 Laravel 面板及 Nginx 联调：五组真实上下行分离连接通过，每组完成 2 MiB 上传和 2 MiB 下载，校验内容一致；覆盖明文、TLS、混合安全设置及 `stream-up`。
- 从真实 HTTP 订阅接口获取配置，完整导入 Mihomo 后通过原生校验及 2 MiB 下载校验。联调使用临时数据库中的简化模板，排除公网规则资源与 TUN 的影响，不改项目默认模板。
- 测试副本、依赖、数据库、证书、客户端、日志均放在源码目录外。未连接 VPS。

## 更新说明

先备份数据库和配置，再在原 Docker 安装目录执行：

```bash
docker compose pull && docker compose up -d
```

使用 `latest` 镜像标签的部署可直接通过以上命令更新；若自行固定版本标签，请先将面板镜像改为 `ghcr.io/toto0912/xboard-u:v1.1.1`。已有数据库、APP_KEY、主题及挂载目录无需更改，不要重新初始化；本次不要求升级 xboard-node-u。

提供 Linux amd64 / arm64 双架构镜像，发布验证通过后同步更新 `latest`。下载附件包含安装脚本、固定版本 Compose 文件、带管理前端的源码包、许可证和 SHA256 校验清单。
