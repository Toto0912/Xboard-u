# xboard-u v2.1.2

修复 CDN 分离后的监听端口显示，并使 Xray 自定义配置生成示例与项目文档一致。

- 开启 CDN「客户端与服务端分离」后，外层只读服务端口和节点列表内部端口展示内层实际监听端口；保存高级设置后及时更新显示。
- 客户端连接端口保持独立；关闭分离时恢复原外层服务端口草稿，不改变服务端配置下发和保存规则。
- Xray SOCKS 出站示例改用扁平的 `settings.address/port/user/pass` 原生格式，路由示例省略旧式 `type: "field"`，并继续自动使用实际服务端监听端口。旧式配置保持兼容，Sing-box 示例不变。
- 同步更新版本标识、README、变更记录和二次开发说明。

此前的本地验证均在独立目录中完成：CDN 端口修复通过 9 项 PHP 回归测试、707 个断言，以及浏览器的显示、保存、刷新、取消和分离开关检查；示例调整通过 JavaScript 语法检查及 8 组组件预览和填入检查，覆盖两内核与分离开关，Xray 示例与两份文档一致。

本次仅更新面板，兼容 xboard-node-u v2.1.0，不新增数据库迁移或必填配置。按原方式更新镜像并重建面板后，刷新管理页面即可使用。

```bash
docker compose pull && docker compose up -d
```
