# xboard-u v2.2.1

完善新版 Surge 的订阅推送，更新默认客户端模板，并修复无可用节点时的配置分组。配套节点端可继续使用 xboard-node-u v2.2.1，本次节点端无改动。

## Surge 订阅

- 新增 VLESS RAW / WebSocket / gRPC / XHTTP，支持 TLS、REALITY、Vision 和已启用的 VLESS Encryption。官方最低版本为 Surge iOS 6.0.0 / Mac 6.12.0，识别到已知旧版本时过滤不支持的 VLESS 节点。
- 按要求忽略 XHTTP 的 `downloadSettings`，仍推送原节点，由同一地址、端口、安全性及路径收发。主端点必须同时允许上下行；不修改 Mihomo / Stash 的独立下行转换。
- 补齐 Trojan WebSocket、TUIC v4/v5、HY2 跳跃端口／间隔以及 Salamander / Gecko 混淆。
- Surge 使用自身 TLS 栈，不输出其他客户端的 uTLS 指纹或 `support-x25519mlkem768` 参数。
- 完善参数转义、节点重名、空组和自动刷新版本识别；不输出服务端私钥、证书、Fallback、路由及出站。无法表达的协议／传输组合跳过并记录不含密钥的原因。

## 默认模板

- Surge 按当前官方语法整理，使用加密 DNS、手动／自动／故障转移组以及持续更新的 Loyalsoldier 规则集，保留订阅自动刷新与信息面板。
- sing-box 1.14、Clash Meta / Stash 使用本次提供的新模板。
- Clash 默认模板改为 **Clash Premium** 配置：保留 RULE-SET、TUN、SCRIPT，补齐 `script.shortcuts.quic`，使用 `normal` 保持 Real-IP DNS 意图。免费开源版 Clash v1.18 无法使用这份完整 Premium 模板，仍使用该内核时请保留兼容的自定义模板。
- 新增数据迁移，仅替换精确匹配的已知旧默认模板，保留管理员自定义内容，并更新订阅缓存代次。已有自定义模板需要手动换用新模板。
- 修复 Sing-box 空 selector / urltest 与 Clash Meta 空组悬空引用；无兼容节点时使用有效的 direct / DIRECT 兜底，不伪造代理节点。

## 升级

继续使用原更新命令：

```bash
docker compose pull && docker compose up -d
```

升级会执行默认模板迁移，不新增数据库列。本次只需更新面板，原有节点通信与服务端配置保持兼容。

## 本地验证

- 独立测试环境完成 160 项完整回归、1816 条断言；最终订阅与模板定向验证完成 27 项测试、216 条断言。
- 官方 sing-box 1.14.4、Mihomo 1.19.34，以及 Clash Premium 2023.08.17 公开归档版均接受有节点、无节点两种完整生成配置。
- Surge / Stash 已验证转换、版本过滤、模板内容与敏感字段隔离，未进行 iOS/macOS 实机导入或公网连接验证。
