# xboard-u v2.4.0

- **全新开源现代管理后台（`admin-frontend/`）**：使用 React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + Shadcn UI 从零构建完整开源管理前端，彻底替换原闭源编译产物及 `AdminAssetPatcher` 补丁机制。
- **全新开源默认用户端（`user-frontend/`）**：使用 React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + Shadcn UI 完整重构并开源默认用户端界面，构建至 `theme/Xboard/assets/`（彻底移除闭源 `umi.js`），完整覆盖登录、注册、找回密码、仪表盘、使用文档、订阅购买与下单、订单支付、节点状态、邀请返利、工单系统、流量明细与个人中心，并保持与第三方主题包的兼容。
- **完整保留 18 个管理模块与全部二次开发特性**：1:1 对齐 Xboard-u 全部节点协议与二次开发功能（VLESS / Trojan Fallback、CDN 客户端/服务端配置分离、HY2 端口跳跃与带宽/伪装配置、Sing-box / Xray 原生自定义出站与路由、机器安装命令、原生 HTML5 拖拽排序模式等），默认按 ID 升序排列机器、权限组与路由列表。
- **交互与编辑器增强**：订阅模板（Sing-box、Clash、Clash Meta、Stash、Surge、Surfboard）与节点自定义 JSON 配置全面接入瘦身懒加载离线版 Monaco Editor；统一 `1970–2099` 可滚动 Shadcn 日期时间选择器、统一侧栏与登录页 `X` 品牌标识，并修复移动端仪表盘宽度溢出。
- **双主题配色与多语言支持**：深海蓝（深色模式）与暖调牛奶白（浅色模式）配色方案；管理端支持简体中文、English、Русский 三语切换，用户端支持简体中文、繁體中文、English、Iran（波斯语 RTL）、日本語、Tiếng Việt、한국어、Русский 共 8 种语言切换。
- **构建与升级兼容**：Dockerfile 新增 `node:22-alpine` 多阶段 `admin-builder` 与 `user-builder` 源码构建；不涉及数据库结构破坏性变更，可直接从 `v2.3.1` 平滑升级。
