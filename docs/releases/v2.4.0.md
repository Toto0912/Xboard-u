# xboard-u v2.4.0 (Pre-release)

- **全新开源现代管理后台（`admin-frontend/`）**：使用 React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + Shadcn UI 从零构建完整开源管理前端，彻底替换原闭源编译产物及 `AdminAssetPatcher` 补丁机制。
- **完整覆盖 18 个管理模块与二次开发特性**：1:1 对齐 Xboard-u 全部节点协议与二次开发功能（VLESS / Trojan Fallback、CDN 客户端/服务端配置分离、HY2 端口跳跃与带宽/伪装配置、Sing-box / Xray 原生自定义出站与路由、机器安装命令、原生 HTML5 拖拽排序模式等）。
- **瘦身懒加载离线版 Monaco Editor**：订阅模板配置（Sing-box、Clash、Clash Meta、Stash、Surge、Surfboard）与节点自定义 JSON 配置全面接入离线 Monaco Editor，原生支持多格式语法高亮、结构校验与一键格式化。
- **全新视觉主题与多语言支持**：采用「深海蓝（深色模式）」与「暖调牛奶白（浅色模式）」配色方案，完整支持简体中文、English、Русский 三语切换。
- **构建与升级兼容**：Dockerfile 新增 `node:22-alpine` 多阶段源码构建；不涉及数据库结构破坏性变更，可直接从 `v2.3.1` 切换镜像标签平滑升级。
