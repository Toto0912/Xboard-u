# xboard-u v2.1.0

2026-11-06 同版本更新：将默认下发监听地址改为 `::`，修复 Sing-box 机器模式等面板节点只监听 IPv4 的问题。在支持双栈的系统上同时接收 IPv4、IPv6 连接；覆盖单节点、机器模式、REST/WebSocket 与 CDN 分离后的服务端配置。

- 设备状态按节点维护完整快照，心跳刷新在线有效期、空快照及时清理，旧 WebSocket 连接关闭不再清除新连接状态。
- Redis 使用节点成员索引及分批读取；在线计数批量写入、相同计数节流，并保留 SQL 失败后的同步重试。
- 优化节点列表的缓存、父节点和权限组查询；流量与用户统计改为分批原子累加，统计任务只保留所需合计，兼容升级前已入队的任务。
- 修正小规模 Horizon 工作进程预算，关闭额外默认进程，优先处理节点同步任务。
- 修正节点排行的日期合计范围，移除统计服务构造时取消内存限制的操作，清理重复处理代码。

本地验证：MySQL 5.7、SQLite 下各 99 项测试 / 1282 条断言通过；用面板实际生成的配置启动 Sing-box，VLESS、SS、HY2 均完成 IPv4、IPv6 真实代理转发验证。此前双端流量、WebSocket 断线恢复、并行设备和流量写入验证均通过。237 用户流量写入由逐用户 237 次 UPDATE 减为 3 次分批 UPDATE。

配套节点端同步发布为 v2.1.0。本次不新增数据库迁移或必填配置，安装与更新命令不变；继续保留用户、订单、流量和节点数据以及原有流量重置规则。按原更新流程重建面板服务及后台进程，使新代码和队列配置生效。

已部署先前 v2.1.0 的用户也需要重新拉取面板镜像并重建服务，节点重新拉取配置后获得双栈监听；本次双栈修复不需要重新安装节点程序。
