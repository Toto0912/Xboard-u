# xboard-u v0.1.0

首个正式版本，基于 cedar2025/Xboard `e68fec5`，搭配 xboard-node-u 使用。

- 修复 HY2 等节点 TLS 内容推送配置保存成功后重新打开为空的问题；已有正确配置保留，已丢失的内容需重新填写。
- 机器安装命令改用 xboard-node-u 正式发布资源，自动识别 Alpine/OpenRC 与普通 Linux，统一使用 xbctl 管理节点端。
- 发布 Linux amd64 / arm64 Docker 镜像、Docker 新装脚本和仅替换镜像的升级编排文件。
- 沿用原数据库、APP_KEY、主题及节点通信接口，没有新增或修改数据库迁移；停用会覆盖二开代码的原版在线自更新。

已通过 PHP 回归测试、SQLite 升级及 MySQL 5.7.44 的 33 表备份升级/回退验证，并完成 Nginx 下的 WebSocket / HY2 联动测试。aaPanel 场景在本地复现其网络与挂载方式，没有连接生产服务器。

已有面板请先阅读 [aaPanel + MySQL 升级指南](https://github.com/Toto0912/Xboard-u/blob/main/docs/AAPANEL-MYSQL-UPGRADE.md)，保留原配置和数据，只替换镜像。新装脚本仅接受空目录，不能用来升级现有面板。

镜像：`ghcr.io/toto0912/xboard-u:v0.1.0`。新装入口及源码构建方式见 [README](https://github.com/Toto0912/Xboard-u#readme)。发布附件包含固定版本的编排文件、带管理前端的源码包和 SHA256 校验文件。
